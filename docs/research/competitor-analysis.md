# Competitor Analysis

## Tools to review
- Cloud Carbon Footprint
- AWS sustainability reporting tools
- Google Cloud Carbon Footprint
- Azure sustainability reporting capabilities

## Comparison dimensions
Provider/service coverage, input requirements, methodology, factor provenance, geographic/time granularity, uncertainty, cost optimization, recommendations, exports, pricing, and target users.

## Differentiation hypothesis
CarbonLens focuses on a small CSV workflow combining traceable estimates, AI-assisted explanation, a prioritized top-three list, and explicit human approval.

This is a positioning hypothesis, not a claim that competitors lack these capabilities. Verify current documentation before publishing comparisons.
